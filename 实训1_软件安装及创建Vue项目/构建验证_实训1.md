## 2. `npm run dev` + 真实渲染断言

命令（在工程目录）：

```
npm run dev -- --port 5171 --strictPort
```

服务输出：

```
VITE v7.3.6  ready in 1159 ms
➜  Local:   http://localhost:5171/
➜  Vue DevTools: Open http://localhost:5171/__devtools__/
```

> ⚠️ 实测：vite 只监听 `[::1]`（IPv6 回环），**`http://127.0.0.1:5171/` 连不上**（`Invoke-WebRequest` 报"无法连接到远程服务器"），必须用 `http://localhost:5171/`。

### 讲义这一处到底对不对

- **`global.css` / `Home.vue` / 精简路由 / 精简 App.vue：讲义全对**，工程也全照做了，且实测生效。
- **唯一值得提醒的一处**：讲义开头写"Nodejs20+ 版本"、并让你双击 `node-v20.15.1-x64.msi` 安装。但本工程 `vite@7` 的 `engines` 是 `^20.19.0 || >=22.12.0`，**Node 20.15.1 低于 20.19.0**，用讲义那个安装包装完再 `npm install` 会出现 `EBADENGINE` 引擎不匹配警告（不一定会失败，但会有警告）。本机用的是 Node v24.17.0，无此问题。这一条属于"讲义版本说明偏旧"，建议在教学时补一句"装 20.19 以上，或直接装 22/24"。
- 讲义未提"修改 `index.html` 的 `<title>`"，工程也保持脚手架默认的 `Vite App` → **不是错**，只是看起来不像自己的项目，可选优化。
