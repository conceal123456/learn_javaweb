### 4. 三条 `index="/manage"` 的点按实测（重要更正）

工程里"管理首页""个人信息""退出登录"三条的 `index` 都是 `/manage`，而路由表把 `/manage`（空子路径）重定向到了 `/manage/detail`。逐条点击实测：

| 场景 | 点击前 | 点击后 | 结论 |
|---|---|---|---|
| 在 `/manage/detail` 点「管理首页」 | `/manage/detail`，高亮 内容展示 | `/manage/detail`，高亮 内容展示 | **无反应**（push 到 `/manage` 重定向回当前页 = 重复导航） |
| 在 `/manage/detail` 点「个人信息」 | `/manage/detail`，高亮 内容展示 | 同上，纹丝不动 | **无反应** |
| 在 `/manage/detail` 点「退出登录」 | 同上 | 同上，纹丝不动 | **无反应** |
| 在 `/manage/admin` 点「管理首页」 | `/manage/admin`，高亮 管理员信息 | URL 变 `/manage/detail`，但**高亮变成 3 条**：管理首页+个人信息+退出登录 | **高亮不唯一，且会"粘住"** |
| 在 `/manage/user` 点「管理首页」 | `/manage/user`，高亮 0 条 | URL 变 `/manage/detail`，高亮 3 条 | 同上 |

"粘住"验证：切到 3 条高亮状态后等 0.5s / 2s 仍是 3 条，再点一次「内容展示」也**没有**恢复成唯一高亮（`lab6b-results.json` 的 A.t0/t500/t2000/afterClickDetail）。截图：`b_lab6_07_three_active.png`（页面停在 `/manage/detail` 的表格上，左侧三条同时蓝色高亮）。

机制（源码核对，非猜测）：`element-plus/es/components/menu/src/menu.mjs:218-219`

```js
const routerResult = router.push(route).then((res) => {
  if (!res) activeIndex.value = index;   // 成功导航时 push 解析为 undefined → 这里把 activeIndex 设成 index
});
```

而 `menu.mjs:285-288` 对 `:default-active` 有 `watch`（会先按新路由把 activeIndex 设成 `/manage/detail`）。当跳转目标是 `/manage`（重定向到 `/manage/detail`）时两者顺序叠加，最终 `activeIndex` 被 `.then` 改成字符串 `/manage` → 三个同 index 的项一起点亮；此后 `defaultActive` 不再变化，watch 不再触发，所以点回「内容展示」也修不回来。**这是 element-plus 与"多条同 index + redirect"写法叠加后的真实行为，不是本次环境问题。**

> 近几版验证文档里写的"三条都不亮 / 点个人信息时地址栏和高亮纹丝不动"只对了一半：在 `/manage/detail` 上点「个人信息」确实无反应，但「三条都不亮」不成立——从别的页面点「管理首页」会变成**三条全亮**。以本次实测为准。

### 6. 子菜单、后退与 `:default-active`

- 子菜单"用户管理"默认展开（`is-opened`），点「管理员信息」→ `/manage/admin`，右侧渲染子页面、高亮唯一、标题"管理员信息"（`b_lab6_04_manage_admin.png`）。
- 进 `/manage/admin` 后按浏览器**后退** → 回到 `/manage/detail`，高亮**自动跟着回到「内容展示」**。
- 不点菜单、直接用 `router.push('/manage/staff')` → 高亮自动变成「普通用户信息」。
- **结论**：`:default-active="router.currentRoute.value.path"` 是响应式的（vue-router 路由一变高亮就跟），虽然名字带 `default`。`b_lab6_06_back_highlight.png`、`b_lab6_09_router_push_staff.png`。

### 7. 控制台

- 每次导航一条 `[VUE_ROUTER_R0025] The next() callback in navigation guards is deprecated.`（vue-router 5.4.0 已废弃 `next()` 写法）。
- 无 JS 异常、无 Vue 警告。
