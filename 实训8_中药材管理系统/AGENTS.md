# 文档排版规范（本项目长期记忆）

以后本项目所有文档（Word / Markdown 导出稿）统一遵守以下规则：

1. **字体颜色**：正文、标题、表格、页眉页脚全部使用黑色（`#000000`），不使用彩色标题、彩色代码或彩色链接。
2. **表格**：使用三线表——只保留顶线、表头下细线、底线；不要竖线，不要内部横线，不要表头底色和斑马纹。
3. **英文字体**：英文、数字统一使用 **Times New Roman**；中文正文使用宋体，中文标题使用黑体。
4. **公式**：公式一律以 **LaTeX 代码**插入（例如 `$E = mc^2$`），不要转成图片，也不要用 Word 公式编辑器另存为图片。
5. 代码块使用等宽排版，字号小于正文，颜色同样为黑色。
6. 前端页面和文档中不要出现个人姓名、学号；按老师原版使用“系统管理员”。

生成脚本：`scripts/build_docx.py`。修改文档样式时先改脚本，再重新生成 `docs/实训8_中药材管理系统_开发文档.docx`。
