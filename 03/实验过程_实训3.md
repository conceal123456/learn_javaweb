> 用法：每节对应作业的一条要求，文字可照抄（建议改成自己的话），图片按标注文件名上传。
> 工程目录：`03/element-plus`。本讲和实训4 共用这一个工程：本讲做"装框架 + 图标"，验证页是 `Home.vue`（路由 `/home`）；实训4 的组件全览页是 `Components.vue`（路由 `/comp`）。

## 0. 关于 Element Plus

Element Plus 是饿了么前端团队开源、持续维护的 Vue3 桌面端 UI 组件库，是 Vue2 时代 Element UI 的升级继任版。

- 官网：`https://element-plus.org`
- 国内镜像（访问快）：`https://cn.element-plus.org/`

组件文档地址格式是 `https://cn.element-plus.org/zh-CN/component/<组件名>`，比如本讲要用的菜单组件就是 `.../component/menu`。查文档这件事本身就是本讲要练的能力。

## 1. 安装 Element Plus 框架

操作步骤：

1. 在 IDEA 里打开底部"终端"，确认当前目录是 vue 工程根目录（提示符里能看到工程名）。
2. 安装生产依赖：

```
npm i element-plus -S
```

`-S` 表示写进 `package.json` 的 `dependencies`（生产依赖）。装完 `package.json` 里会多出一行 `"element-plus": "^2.14.x"`。

3. 修改 `src/main.js`，引入组件库本体、样式文件、中文语言包，并用 `app.use()` 全局注册：

```js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import './assets/global.css'

import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

const app = createApp(App)

app.use(router)
app.use(ElementPlus, {
  locale: zhCn,
})

app.mount('#app')
```

三行 import 缺一不可：只 import `ElementPlus` 不引 `index.css` 的话，组件能用但完全没有样式，页面会是一堆裸标签。

4. 保存后 Vite 会热更新，不用重启；如果没生效就手动重启一次 `npm run dev`。

## 2. 用按钮组件验证配置是否生效

操作步骤：在 `Home.vue` 里放一组不同 `type` 的按钮，能正常渲染出 Element Plus 的配色和圆角，就说明框架装好了。

```html
<el-button>默认按钮</el-button>
<el-button type="primary">主要按钮</el-button>
<el-button type="success">成功按钮</el-button>
<el-button type="warning">警告按钮</el-button>
<el-button type="danger">危险按钮</el-button>
<el-button type="info">信息按钮</el-button>

<el-button type="primary" plain>plain 朴素</el-button>
<el-button type="success" round>round 圆角</el-button>
<el-button type="danger" disabled>disabled 禁用</el-button>
<el-button type="primary" link>link 链接</el-button>
```

观察结果：六种 type 分别是灰、蓝、绿、橙、红、灰蓝；`plain` 是浅底描边；`round` 两端变圆；`disabled` 变淡且点不动；`link` 看起来像超链接。

## 3. 全局使用 Element Plus 图标

操作步骤：

1. 安装图标包：

```
npm install @element-plus/icons-vue
```

2. 在 `main.js` 里把全部图标一次性注册成全局组件：

```js
import * as ElementPlusIconsVue from '@element-plus/icons-vue'

for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}
```

`import * as` 把整个包的图标都收进一个对象，`Object.entries()` 拿到"名字 + 组件"的键值对数组，循环里用 `app.component(名字, 组件)` 逐个注册。注册完之后，任何组件的模板里都能直接写 `<House />`、`<School />` 这样的标签，不用每个文件都 import。

3. 到官网"图标"页找需要的图标，把它的组件名抄过来用。

```html
<div style="display: flex; gap: 60px;">
  <span style="color: #6666">
    <el-icon :size="60" color="#6666" style="top: 4px"><School /></el-icon> 安中医
  </span>
  <span style="color: #666666">
    <el-icon :size="60" color="#666666"><School /></el-icon> 安中医
  </span>
</div>
```

`<el-icon>` 是容器，`:size` 控制大小，`color` 属性或外层 CSS 的 `color` 控制颜色，里面那对标签（`<School />`）才是具体图标。

观察结果：两个图标并排看，左边明显偏淡、像蒙了层灰，右边是正常的中灰。

截图：同上一张图（`03_按钮type与图标颜色对比.png` 的下半部分），或者单独截 `演示截图/03_图标颜色对比.png`。

## 4. 遇到的问题与解决方法（本讲重点）

1. **`app.use(ElementPlus)` 报错或组件不生效。** 这句必须在 `createApp(App)` 之后执行，写在前面时 `app` 还不存在。
2. **按钮全都没样式，就是浏览器默认样子。** 漏了 `import 'element-plus/dist/index.css'`。组件库本体和它的样式表是两件事，都要引。
3. **图标颜色偏淡，改成 `#666666` 就正常了。** 这是本讲最容易踩的坑：讲义示例写的是 `color="#6666"`，十六进制颜色只有 3 位（`#666`）和 6 位（`#666666`）两种合法写法，4 位的 `#6666` 会被解析成"RGBA 四通道"形式，最后一位 `6` 当成透明度，结果是半透明的灰，视觉上就是发淡。改成 6 位即可。我特意把两种写法放在同一页左右对比，截图里差别很明显。
4. **图标标签写了但页面上什么都没有。** 检查两件事：`main.js` 里的全局注册循环有没有跑，以及图标名拼写对不对（区分大小写，`<school />` 找不到组件）。
5. **`<el-icon style="top: 4px">` 这个 top 有没有用。** 有用。查 `node_modules/element-plus/theme-chalk/el-icon.css`，`.el-icon` 的 `position` 是 `relative`，所以 `top` 会生效，这是用来微调图标和旁边文字基线对齐的。
