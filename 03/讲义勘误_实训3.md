# 实训3 讲义勘误报告（前端 Element Plus 框架）

审核对象：`03/实训3/实训3_前端Element Plus框架.docx`
审核方式：逐页读正文与截图，比对 Element Plus 官方用法。

## 总体结论
安装与全局引入 Element Plus、全局注册图标的步骤正确。发现一处颜色写法错误，以及一处需要强调的引入顺序。

## 问题清单

### 1.（一般）颜色值 `#6666` 是错的，应为 `#666666`
图标示例里两处写了非法/非预期的颜色：
```html
<span style="margin-left: 30px; color: #6666">
  <el-icon :size="60" color="#6666" style="top: 4px"><School /></el-icon> 安中医
</span>
```
`#6666` 只有 4 位，按 CSS 会被解析成 `#RGBA`（即半透明灰，透明度约 0.4），不是作者想要的实色中灰。
建议：改为 `#666666` 或简写 `#666`。

### 2.（提示）main.js 里 `app.use(ElementPlus, ...)` 必须在 `const app = createApp(App)` 之后
讲义说"将下面代码放在合适的位置"，其中：
```js
app.use(ElementPlus, { locale: zhCn })
```
用到了变量 `app`。若学生把它放到 `const app = createApp(App)` 之前，会报 `app is not defined`。
建议：明确"这段要放在 `createApp` 之后、`mount` 之前"。

## 正确的部分（确认无误）
- 安装命令 `npm i element-plus -S`、`npm install @element-plus/icons-vue` 正确。
- 引入 `import 'element-plus/dist/index.css'` 与 `import zhCn from 'element-plus/es/locale/lang/zh-cn'` 路径正确。
- 全局注册图标（遍历 `ElementPlusIconsVue` 调 `app.component`）写法正确。
