# 基础补课 · 训练营

这个文件夹是为了解决一个问题：**仓库里有 1037 行标准答案，但没有一行是你自己写的。**

所以这里故意**不提供任何可以直接抄的代码**，只提供任务、验收标准和原理。

## 怎么开始

双击打开 **[补基础训练营.html](补基础训练营.html)** 就行（不用装环境、不用联网、不用服务器）。

里面有：

| 板块 | 作用 |
|---|---|
| 三个错觉 | 解释"为什么跟着敲觉得没用" |
| 知识地图 | 五层能力，标出你仓库里**有**的和**缺**的 |
| 九张任务卡 | L0–L8，每关只有"要做什么"+"怎么算过关"，验收项可勾选 |
| 自测题库 | 42 题，答案默认折叠，**先答后看** |
| 四块原理 | 请求链路 8 跳、两层状态码、Promise、跨域，全部用你自己的文件讲 |
| 学习法 | 30 分钟一节的节奏 + 三条自检问题 |

勾选进度会保存在浏览器本地（localStorage），关掉再开还在；右上角可以重置。

## 你的练习代码放这里

`js练习/` 是你自己敲代码的地方，L1–L4 的练习文件都建在这个目录下：

```
基础补课/
├─ 补基础训练营.html      ← 主入口，双击打开
├─ README.md              ← 本文件
└─ js练习/                ← 你自己的代码，随便写
    ├─ l1.js              ← L1 的六道语法题
    ├─ l2.js              ← L2 的数组对象题
    ├─ l3.js / math.js    ← L3 的模块化
    └─ l4.js              ← L4 的异步题
```

> 为什么单独建目录：不要去改 `01/hello-vue` 那些工程，它们是"对照物"，改乱了后面就没法比对了。

## 顺序

**L0 → L1 → L2 → L3 → L4 → L5 → L6 → L7 → L8**，不要跳。

- L1–L3 是语法地基，一天能过完；
- **L4（异步）一定要单独留时间慢慢磨**，L7 卡不卡全看这一关；
- L5–L6 不写复杂代码，是"观察 + 配置"，但排错能力全靠它们；
- **L7 是分水岭**（把 `07/xm-pro` 的前后端真正接通），L8 是收尾闭环。

## 卡住了怎么办

把这三样发我，我会指方向但**不直接给答案**：

1. 你的代码
2. **报错原文**（原样粘贴，不要转述）
3. 你已经试过什么

只要说"帮我写一下"，就等于把训练营的意义取消了。

## 内容可信度

训练营里出现的所有文件路径、类名、行号、报错现象，都来自本仓库的真实文件；
`/hello`、`/number`、`/map`、`/result`、`/business` 五个接口的返回结果，
是用仓库自带的 `07/_verify_lab7.ps1` 实测跑出来抄进去的（全部 HTTP 200，异常被全局处理器吃掉）。
