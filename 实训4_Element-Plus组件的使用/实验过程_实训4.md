## 2. 下拉选择器 Select 练习

`el-select` 配 `el-option`，选项用 `v-for` 遍历数组生成，选中值由 `v-model` 接住。

```html
<el-select v-model="data.value" placeholder="请选择中药" style="width: 230px">
  <el-option v-for="item in data.options" :key="item.id" :label="item.name" :value="item.name" />
</el-select>
<span> 你的选择：{{ data.value }}</span>
```

```js
options: [{ id: 1, name: '虫草' }, { id: 2, name: '人参' }, { id: 3, name: '鹿茸' }, { id: 4, name: '牛黄' }]
```

观察结果：展开下拉能看到 4 个选项，选"人参"后右侧"你的选择："立刻显示"人参"。`label` 是显示出来的文字，`value` 是真正存进变量的值，这里两者都用了 `item.name`。

## 3. 单选、多选组件练习

### 3.1 单选按钮组

```html
<el-radio-group v-model="data.sex">
  <el-radio value="男">男</el-radio>
  <el-radio value="女">女</el-radio>
</el-radio-group>
<span> 你的选择是：{{ data.sex }}</span>

<el-radio-group v-model="data.tag" size="large">
  <el-radio-button label="我发布的内容" value="1" />
  <el-radio-button label="我点赞的内容" value="2" />
  <el-radio-button label="我收藏的内容" value="3" />
</el-radio-group>
```

两种形态：`el-radio` 是圆点单选，`el-radio-button` 是按钮样式的单选，都放在 `el-radio-group` 里、共用同一个 `v-model`。`size="large"` 控制按钮组尺寸。

### 3.2 多选框与多选框组

```html
<el-checkbox v-model="checked1" label="冬虫" size="large" />
<el-checkbox v-model="checked2" label="人参" size="large" />

<el-checkbox-group v-model="data.checkList">
  <el-checkbox v-for="item in data.cols" :key="item.id" :label="item.name" :value="item.name" />
</el-checkbox-group>
<div>你的选择是：{{ data.checkList }}</div>
```

关键区别：独立多选框的 `v-model` 绑的是**布尔值**（勾上 true、取消 false）；多选框组的 `v-model` 绑的是**数组**，每勾一项就往数组里加一个值，页面上能直接看到 `["阿胶","陈皮"]` 这样的结果。

## 4. Image 图片组件练习

### 4.1 五种 fit 适配模式对比

同图同尺寸，只换 `fit`，一眼看出差别：

```html
<span v-for="fit in fits" :key="fit" style="display:inline-block; text-align:center; margin-right:10px">
  {{ fit }}<br />
  <el-image style="width: 100px; height: 100px" :src="img" :fit="fit" />
</span>
```

```js
const fits = ['fill', 'contain', 'cover', 'none', 'scale-down']
```

观察结果（截图里能直接量出来）：`fill` 把图拉伸填满、比例变形；`contain` 完整装下、上下留白；`cover` 等比放大裁掉边缘、铺满框；`none` 原图尺寸直接摆、只露出中间一小块；`scale-down` 在 contain 和 none 里取更小的那个。

截图：`演示截图/04_05_图片五种fit对比.png`

### 4.2 懒加载 lazy

```html
<div style="height: 240px; overflow-y: auto; border: 1px solid #eee;">
  <el-image v-for="(u, i) in lazyList" :key="i" :src="u" lazy style="display:block; height:150px; margin-bottom:8px" />
</div>
```

外层容器高度固定、出垂直滚动条，`lazy` 打开后只有滚进可视区域的那张才发网络请求。验证方法：F12 打开 Network 面板，勾选 Disable cache，慢慢往下滚，能看到图片请求是一批一批冒出来的，不是一进来就全要。

截图：`演示截图/04_06_图片懒加载.png`，另配一张 Network 面板的截图更有说服力。

### 4.3 大图预览与缩放

```html
<el-image style="width: 100px; height: 100px" :src="img" :preview-src-list="imgs" :initial-index="0" fit="cover" />
```

`preview-src-list` 给一个数组，点缩略图就弹全屏预览器，支持滚轮缩放、拖拽平移、左右切换多张；`initial-index="0"` 表示打开时定位到第一张。

顺带说明：`show-progress` 这个属性控制的是预览器里显示"当前第几张 / 共几张"的序号进度，不是图片加载进度条，容易望文生义。

截图：`演示截图/04_07_图片预览缩略图.png`，再补一张点开大图后的全屏预览截图。

## 5. Carousel 走马灯轮播图练习

### 5.1 基础轮播

```html
<el-carousel height="200px" style="width: 460px" :interval="2000" arrow="hover">
  <el-carousel-item v-for="(u, i) in imgs" :key="i">
    <img style="width: 100%; height: 100%; object-fit: cover;" :src="u" alt="轮播图片" />
  </el-carousel-item>
</el-carousel>
```

`el-carousel` 是外壳，里面每个 `el-carousel-item` 是一张，放几张就写几个（这里用 `v-for` 遍历图片数组）。`height` 定高，`:interval="2000"` 每 2 秒切一张，`arrow="hover"` 表示鼠标悬停时才显示左右箭头。默认鼠标移入就暂停、移出继续，这正是作业要的"悬停暂停"。

**这里踩过一个坑**：写成 `interval="3000"` 是错的。`interval` 要的是数字，不加冒号传进去的是字符串，控制台会报 `Invalid prop: type check failed for prop "interval". Expected Number with value 3000, got String with value "3000"`。凡是数字类型的属性都必须加冒号。

> **一处更正（2026-10-16 回源核实）**：这里原写"写成 `interval="3000"` 是无效的"，**不准确**。查 `element-plus/es/components/carousel/src/use-carousel.mjs:51-52`，源码是
> `if (props.interval <= 0 || !props.autoplay || timer.value) return;` / `timer.value = setInterval(() => playSlides(), props.interval);`
> ——`"3000" <= 0` 和 `setInterval(fn, "3000")` 都会把字符串**隐式转成数字**，所以**轮播功能上照常工作，只是控制台多一条告警**。
> 这反而更危险：告警被忽略、规则被学歪。对比 `autoplay="false"`——字符串 `"false"` 是**真值**，效果和你的意图正好相反。**凡 Number / Boolean 类型的 prop，一律加冒号。**

### 5.2 卡片式轮播

```html
<el-carousel height="200px" style="width: 640px" type="card" :interval="2000">
```

只多一个 `type="card"`。区别：普通轮播一次只显示一张、铺满容器；卡片式当前这张居中放大，左右两张各露一部分并缩小，有立体层次感，适合展示少量重点图片。

截图：`演示截图/04_08_走马灯轮播.png`、`演示截图/04_09_卡片式轮播.png`

## 6. DatePicker 日期选择器练习

四种形态，注意 `format` 是页面上显示成什么样，`value-format` 是绑定到 JS 变量里的值是什么格式（提交给后端用这个）。

```html
<el-date-picker v-model="data.date" type="date" format="YYYY-MM-DD" value-format="YYYY-MM-DD" placeholder="选日期" />

<el-date-picker v-model="data.datetime" type="datetime" format="YYYY-MM-DD HH:mm:ss" value-format="YYYY-MM-DD HH:mm:ss" placeholder="选日期时间" />

<el-time-picker v-model="data.time" placeholder="选择时间" />

<el-date-picker v-model="data.daterange" type="daterange" range-separator="至"
  start-placeholder="开始" end-placeholder="结束" format="YYYY-MM-DD" value-format="YYYY-MM-DD" />
```

观察结果：`type="date"` 只选到日；`type="datetime"` 选到日期加时分秒；`el-time-picker` 只选时间；`type="daterange"` 出双日历，选完是一段区间，绑定的值是一个两元素数组，页面上我拼成"2026-10-01 到 2026-10-08"这样显示。不写 `value-format` 时变量里存的是 JS Date 对象，序列化成 JSON 会带一串英文格式和时区，一般都要显式指定成 `YYYY-MM-DD`。

截图：`演示截图/04_10_日期选择四种.png`（再补一张日历面板展开的）

## 7. Table 数据表格与 Pagination 分页组件练习

### 7.1 表格

```html
<el-table :data="pagedData" style="width: 100%" stripe>
  <el-table-column prop="name" label="名称" width="180" />
  <el-table-column prop="date" label="日期" width="180" />
  <el-table-column prop="address" label="主产地" />
  <el-table-column label="操作" width="200">
    <template #default="scope">
      <el-button size="small" @click="view(scope.row)">查看</el-button>
      <el-button type="danger" size="small" @click="del(scope.row.id)">删除</el-button>
    </template>
  </el-table-column>
</el-table>
```

`:data` 绑数组，`prop` 对应每条数据里的字段名，`label` 是表头文字，`stripe` 加斑马纹。最后一列没有 `prop`，用 `#default="scope"` 作用域插槽往每行塞按钮，`scope.row` 就是当前行那条数据。

### 7.2 分页

```html
<el-pagination
  v-model:current-page="currentPage"
  v-model:page-size="pageSize"
  :page-sizes="[3, 5, 10]"
  background
  layout="total, sizes, prev, pager, next, jumper"
  :total="tableData.length"
  style="margin-top: 12px"
/>
```

四个核心属性：`current-page` 当前页码、`page-size` 每页条数、`total` 总条数、`layout` 分页条上有哪些块和顺序。`background` 让页码有底色方块。

**分页要真的动起来，必须自己按页码切数组**，光摆一个 `el-pagination` 组件是不会改变表格内容的：

```js
const pagedData = computed(() => {
  const start = (currentPage.value - 1) * pageSize.value
  return tableData.slice(start, start + pageSize.value)
})
```

表格改成绑 `pagedData`。另外 `:page-sizes` 里的候选值要包含 `pageSize` 的初值，否则初始显示会对不上。

截图：`演示截图/04_11_表格分页与操作列.png`（再补一张翻到第 2 页、表格内容确实换掉的）

## 8. 弹窗及删除功能练习

作业这条要求的是"弹窗"，而讲义第十一节标题写"弹窗"、内容其实是表格操作列加一个原生 `alert()`，并没有出现 `el-dialog`。所以我按作业要求补齐了真正的 Element Plus 弹窗，一共三种：

### 8.1 新增：el-dialog 表单弹窗

```html
<el-button type="primary" @click="openAdd">新增</el-button>

<el-dialog v-model="dialogVisible" title="新增中药材" width="420px">
  <el-form label-width="70px">
    <el-form-item label="名称"><el-input v-model="form.name" placeholder="如：大别山天麻" /></el-form-item>
    <el-form-item label="日期"><el-date-picker v-model="form.date" type="date" format="YYYY-MM-DD" value-format="YYYY-MM-DD" placeholder="选日期" style="width: 100%" /></el-form-item>
    <el-form-item label="主产地"><el-input v-model="form.address" placeholder="如：六安金寨、霍山" /></el-form-item>
  </el-form>
  <template #footer>
    <el-button @click="dialogVisible = false">取消</el-button>
    <el-button type="primary" @click="save">保存</el-button>
  </template>
</el-dialog>
```

```js
const dialogVisible = ref(false)
const form = reactive({ name: '', date: '', address: '' })
let nextId = 100
const openAdd = () => {
  form.name = ''; form.date = ''; form.address = ''
  dialogVisible.value = true
}
const save = () => {
  if (!form.name) {
    ElMessage.warning('名称不能为空')
    return
  }
  tableData.push({ id: nextId++, name: form.name, date: form.date, address: form.address })
  dialogVisible.value = false
  ElMessage.success('已新增：' + form.name)
}
```

弹窗显隐完全由 `v-model` 绑的那个布尔值控制：点"新增"置 true 就弹出，保存或取消置 false 就关闭。`#footer` 插槽放底部按钮。保存时先校验名称非空，用 `ElMessage.warning` 给提示。

截图：`演示截图/04_12_弹窗_新增表单.png`

### 8.3 删除：先确认框，再真删

```js
const del = (id) => {
  const row = tableData.find((x) => x.id === id)
  ElMessageBox.confirm(`确定删除【${row.name}】这条数据吗？`, '删除确认', {
    type: 'warning',
    confirmButtonText: '确定',
    cancelButtonText: '取消',
  })
    .then(() => {
      tableData.splice(tableData.findIndex((x) => x.id === id), 1)
      ElMessage.success('已删除 id = ' + id)
    })
    .catch(() => ElMessage.info('已取消删除'))
}
```

`ElMessageBox.confirm` 返回 Promise：点确定走 `then` 真的删数据，点取消或关闭走 `catch`。删除用 `findIndex` 找到下标再 `splice`，表格和分页都会自动跟着刷新。

截图：`演示截图/04_13_弹窗_删除确认框.png`，再补一张删完之后行数少一条、总条数变小的

## 9. 遇到的问题与解决方法（本讲汇总）

1. **轮播间隔不生效。** `interval="3000"` 传成了字符串，控制台报类型不符。改为 `:interval="3000"`。
2. **分页点了没反应，翻页表格内容不变。** 原因是 `total` 只是给分页组件算页数用的，和表格数据没有任何关系，得自己写 `computed` 按 `currentPage` 和 `pageSize` 切数组（见 7.2）。
3. **`pageSize` 初值不在 `page-sizes` 候选里。** 比如初值 100、候选 `[5,10,15,50]`，下拉框显示会不自洽。两边对齐即可。
4. **`class="mt-2"` 写了没效果。** 那是 Tailwind 的工具类，工程里没装 Tailwind，这行等于白写。要间距就老老实实写 `style="margin-top: 8px"`。
5. **删除点了页面不动。** 如果表格数据是用普通数组 `const tableData = [...]` 定义的，`splice` 之后视图不会更新，因为不是响应式的。必须 `reactive([...])` 或 `ref([...])` 包起来。
6. **`:background` 和 `background` 的区别。** 分页组件这个是布尔属性，直接写 `background` 就是 true；写成 `:background` 会变成"绑定一个叫 background 的变量"，变量不存在拿到 undefined，底色反而没了。
7. **图片懒加载看不出效果。** 因为图片太少或容器没限高，全部都在可视区内。给外层容器固定高度加 `overflow-y: auto`，再放 8 张以上才明显。
8. **原生 `alert()` 挡住了自动化截图。** 弹框会阻塞页面渲染，脚本截图时页面卡住等人工点掉。我在页面上加了 `?open=add` / `?open=del` / `?open=view` 三个参数，访问时自动弹出对应弹窗，截图就稳定了；平时不带参数正常用。
