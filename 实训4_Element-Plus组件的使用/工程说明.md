# 实训4 · 工程说明

按讲义，**实训3 和 实训4 是同一个工程的连续两步**：实训3 装好 Element Plus、全局注册图标并验证；实训4 在同一个工程里继续写组件页。

所以本仓库没有给实训4 复制第二份工程，工程在：

```
../实训3_前端ElementPlus框架/工程/element-plus/
```

## 怎么跑

```bash
cd "实训3_前端ElementPlus框架/工程/element-plus"
npm install
npm run dev
```

浏览器打开 <http://localhost:5173/comp>，就是本讲（实训4）要交的组件页。

## 三个路由分别属于哪一讲

| 路由 | 文件 | 对应内容 |
|---|---|---|
| `/home` | `src/views/Home.vue` | 实训3：Element Plus 安装、图标全局注册、图标颜色对比 |
| `/comp` | `src/views/Components.vue` | **实训4**：8 组组件的完整用法（本讲成果） |
| `/comp-orig` | `src/views/ComponentsOriginal.vue` | 实训4 讲义字面版（保留用于对照分页/背景色等不生效问题） |
