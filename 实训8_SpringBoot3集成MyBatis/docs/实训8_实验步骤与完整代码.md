## 4. 配置 application.yml

对应讲义：`二、配置 MyBatis → 1. 配置 mybatis 实体和 xml 映射`。

文件位置：`springboot/src/main/resources/application.yml`

```yaml
server:
  port: 8080

spring:
  datasource:
    # 注意：数据库名是 xm-pro（中划线），不是 xm_pro
    url: jdbc:mysql://localhost:3306/xm-pro?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: ${DB_USERNAME:root}
    password: ${DB_PASSWORD:123456}
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis:
  mapper-locations: classpath:mapper/*.xml
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
    map-underscore-to-camel-case: true

pagehelper:
  helper-dialect: mysql
  reasonable: true
  support-methods-arguments: true
  params: count=countSql
```

三个 MyBatis 配置的作用：

| 配置 | 作用 |
|---|---|
| `mapper-locations: classpath:mapper/*.xml` | 告诉 MyBatis 去 `resources/mapper` 下找 XML |
| `log-impl: ...StdOutImpl` | 在控制台打印真正执行的 SQL 和参数，方便排错 |
| `map-underscore-to-camel-case: true` | 数据库下划线字段自动映射成 Java 驼峰属性 |

> `username` / `password` 写的是 `${DB_USERNAME:root}` 这种形式：
>
> - 没有配置环境变量时，使用冒号后面的默认值 `root` / `123456`；
> - 如果本机密码不是 `123456`，可以改默认值，或者设置环境变量 `DB_PASSWORD`。

## 5. 实体类 Employee

对应讲义：`10. 新建一个包：entity，新建一个实体类 Employee`。

文件位置：`springboot/src/main/java/com/example/entity/Employee.java`

```java
package com.example.entity;

/**
 * 员工实体，字段与 employee 表一一对应。
 */
public class Employee {

    private Integer id;
    private String name;
    private String sex;
    private String no;
    private Integer age;
    private String description;

    public Integer getId() {
        return id;
    }

    public void setId(Integer id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getSex() {
        return sex;
    }

    public void setSex(String sex) {
        this.sex = sex;
    }

    public String getNo() {
        return no;
    }

    public void setNo(String no) {
        this.no = no;
    }

    public Integer getAge() {
        return age;
    }

    public void setAge(Integer age) {
        this.age = age;
    }

    public String getDescription() {
        return description;
    }

    public void setDescription(String description) {
        this.description = description;
    }
}
```

要点：

1. 实体类属性名要和数据库字段对应：`id、name、sex、no、age、description`。
2. 必须有 **getter / setter**，否则 MyBatis 无法把查询结果装进对象，Jackson 也无法把对象转成 JSON。
3. `id` 和 `age` 用 `Integer`，其余用 `String`。

## 6. 统一返回类 Result

文件位置：`springboot/src/main/java/com/example/common/Result.java`

```java
package com.example.common;

/**
 * 统一返回结果。
 *
 * @param <T> 返回数据的类型
 */
public class Result<T> {

    private String code;
    private String msg;
    private T data;

    public static <T> Result<T> success() {
        Result<T> result = new Result<>();
        result.setCode("200");
        result.setMsg("请求成功");
        return result;
    }

    public static <T> Result<T> success(T data) {
        Result<T> result = success();
        result.setData(data);
        return result;
    }

    public static <T> Result<T> error() {
        Result<T> result = new Result<>();
        result.setCode("500");
        result.setMsg("系统错误");
        return result;
    }

    public static <T> Result<T> error(String code, String msg) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMsg(msg);
        return result;
    }

    public String getCode() {
        return code;
    }

    public void setCode(String code) {
        this.code = code;
    }

    public String getMsg() {
        return msg;
    }

    public void setMsg(String msg) {
        this.msg = msg;
    }

    public T getData() {
        return data;
    }

    public void setData(T data) {
        this.data = data;
    }
}
```

返回格式固定为：

```json
{
  "code": "200",
  "msg": "请求成功",
  "data": {}
}
```

- `code`：业务状态码，`200` 成功，`500` 失败；
- `msg`：提示信息；
- `data`：真正的数据，可以是对象、集合、字符串或 `null`。

## 7. Mapper 接口

对应讲义：`3. 在包 example 内新建一个 mapper 包`、`4. 新建一个接口`、`5. 产生关联`。

文件位置：`springboot/src/main/java/com/example/mapper/EmployeeMapper.java`

```java
package com.example.mapper;

import com.example.entity.Employee;
import org.apache.ibatis.annotations.Select;

import java.util.List;

/**
 * 员工 Mapper。
 *
 * 增删改查的 SQL 写在 resources/mapper/EmployeeMapper.xml 中，
 * 方法名必须和 XML 里的 id 完全一致。
 */
public interface EmployeeMapper {

    List<Employee> selectAll();

    Employee selectById(Integer id);

    @Select("SELECT id, name, sex, no, age, description FROM employee WHERE id = #{id}")
    Employee selectByIdWithAnnotation(Integer id);

    int insert(Employee employee);

    int update(Employee employee);

    int deleteById(Integer id);
}
```

要点：

- Mapper 接口只写方法声明，不写实现；
- MyBatis 启动时用动态代理生成实现类；
- `selectByIdWithAnnotation` 用 `@Select` 注解直接写 SQL，演示“简单查询可以用注解”；
- 其余方法都去 XML 里找同名 `id` 的 SQL。

### 7.1 让 Spring Boot 扫描 Mapper

对应讲义：`6. 告诉 SpringBoot 如何扫描 mapper 包`。

文件位置：`springboot/src/main/java/com/example/SpringbootApplication.java`

```java
package com.example;

import org.mybatis.spring.annotation.MapperScan;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
@MapperScan("com.example.mapper")
public class SpringbootApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringbootApplication.class, args);
    }
}
```

`@MapperScan("com.example.mapper")` 会扫描这个包下所有 Mapper 接口，并注册成 Spring Bean。

> 也可以在每个 Mapper 接口上写 `@Mapper`，两种方式选一种即可；同时写也不会报错，但没必要。

## 8. Mapper XML

对应讲义：`2. 新建 EmployeeMapper.xml 文件`、`5. namespace 关联`、`14. 写上查询语句`。

文件位置：`springboot/src/main/resources/mapper/EmployeeMapper.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="com.example.mapper.EmployeeMapper">

    <!-- 查询全部 -->
    <select id="selectAll" resultType="com.example.entity.Employee">
        SELECT id, name, sex, no, age, description
        FROM employee
        ORDER BY id
    </select>

    <!-- 按 id 查询 -->
    <select id="selectById" resultType="com.example.entity.Employee">
        SELECT id, name, sex, no, age, description
        FROM employee
        WHERE id = #{id}
    </select>

    <!-- 新增：useGeneratedKeys 把自增主键回填到 employee.id -->
    <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO employee (name, sex, no, age, description)
        VALUES (#{name}, #{sex}, #{no}, #{age}, #{description})
    </insert>

    <!-- 修改 -->
    <update id="update">
        UPDATE employee
        SET name        = #{name},
            sex         = #{sex},
            no          = #{no},
            age         = #{age},
            description = #{description}
        WHERE id = #{id}
    </update>

    <!-- 删除 -->
    <delete id="deleteById">
        DELETE FROM employee WHERE id = #{id}
    </delete>

</mapper>
```

三个核心点，必须完全对应：

| XML 里的写法 | 必须和谁对应 | 写错会怎样 |
|---|---|---|
| `namespace="com.example.mapper.EmployeeMapper"` | Mapper 接口的全限定类名 | `Invalid bound statement (not found)` |
| `<select id="selectAll">` | 接口方法名 `selectAll` | 同上 |
| `resultType="com.example.entity.Employee"` | 实体类全限定类名 | 查询结果无法封装 |

`#{id}`、`#{name}` 是 MyBatis 的占位符，相当于 JDBC 的 `?`，会使用预编译，能防 SQL 注入。

> `selectByIdWithAnnotation` 用的是 `@Select` 注解，**不要**再在 XML 里写一个同 id 的 `<select>`，否则会报“Mapped Statements collection already contains value”。

## 9. Service 业务层

对应讲义：`7. 新建 service 包`、`12. 完善 EmployeeService.java 代码`。

文件位置：`springboot/src/main/java/com/example/service/EmployeeService.java`

```java
package com.example.service;

import com.example.entity.Employee;
import com.example.mapper.EmployeeMapper;
import com.github.pagehelper.PageHelper;
import com.github.pagehelper.PageInfo;
import jakarta.annotation.Resource;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class EmployeeService {

    @Resource
    private EmployeeMapper employeeMapper;

    public List<Employee> selectAll() {
        return employeeMapper.selectAll();
    }

    public Employee selectById(Integer id) {
        return employeeMapper.selectById(id);
    }

    public Employee selectByIdWithAnnotation(Integer id) {
        return employeeMapper.selectByIdWithAnnotation(id);
    }

    public PageInfo<Employee> selectPage(Integer pageNum, Integer pageSize) {
        PageHelper.startPage(pageNum, pageSize);
        List<Employee> list = employeeMapper.selectAll();
        return PageInfo.of(list);
    }

    public int insert(Employee employee) {
        return employeeMapper.insert(employee);
    }

    public int update(Employee employee) {
        return employeeMapper.update(employee);
    }

    public int deleteById(Integer id) {
        return employeeMapper.deleteById(id);
    }
}
```

要点：

- `@Service` 把类交给 Spring 管理；
- `@Resource` 把 Mapper 代理对象注入进来；
- Controller 不直接调 Mapper，必须经过 Service；
- 现在业务简单，Service 只是中转；以后有事务、校验、计算，都写在这里。

## 10. Controller 控制层

对应讲义：`8. 新建类 EmployeeController`、`11. 完善 EmployeeController 的代码`。

文件位置：`springboot/src/main/java/com/example/controller/EmployeeController.java`

```java
package com.example.controller;

import com.example.common.Result;
import com.example.entity.Employee;
import com.example.service.EmployeeService;
import com.github.pagehelper.PageInfo;
import jakarta.annotation.Resource;
import org.springframework.web.bind.annotation.CrossOrigin;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;

@CrossOrigin
@RestController
@RequestMapping("/employee")
public class EmployeeController {

    @Resource
    private EmployeeService employeeService;

    /**
     * 查询全部员工。
     */
    @GetMapping("/selectAll")
    public Result<List<Employee>> selectAll() {
        return Result.success(employeeService.selectAll());
    }

    /**
     * 按 id 查询（路径参数）。
     */
    @GetMapping("/selectById/{id}")
    public Result<Employee> selectById(@PathVariable Integer id) {
        return Result.success(employeeService.selectById(id));
    }

    /**
     * 按 id 查询（查询参数，演示 @Select 注解方式）。
     */
    @GetMapping("/selectOne")
    public Result<Employee> selectOne(@RequestParam Integer id) {
        return Result.success(employeeService.selectByIdWithAnnotation(id));
    }

    /**
     * 分页查询。
     */
    @GetMapping("/selectPage")
    public Result<PageInfo<Employee>> selectPage(
            @RequestParam(defaultValue = "1") Integer pageNum,
            @RequestParam(defaultValue = "10") Integer pageSize) {
        return Result.success(employeeService.selectPage(pageNum, pageSize));
    }

    /**
     * 新增员工，id 由数据库自增。
     */
    @PostMapping("/insert")
    public Result<String> insert(@RequestBody Employee employee) {
        int rows = employeeService.insert(employee);
        return rows > 0 ? Result.success("新增成功") : Result.error("500", "新增失败");
    }

    /**
     * 修改员工，必须传 id。
     */
    @PutMapping("/update")
    public Result<String> update(@RequestBody Employee employee) {
        int rows = employeeService.update(employee);
        return rows > 0 ? Result.success("修改成功") : Result.error("500", "修改失败");
    }

    /**
     * 按 id 删除员工。
     */
    @DeleteMapping("/delete/{id}")
    public Result<String> delete(@PathVariable Integer id) {
        int rows = employeeService.deleteById(id);
        return rows > 0 ? Result.success("删除成功") : Result.error("500", "删除失败");
    }
}
```

注解解释：

| 注解 | 作用 |
|---|---|
| `@RestController` | `@Controller + @ResponseBody`，返回值自动转 JSON |
| `@RequestMapping("/employee")` | 给整个类加统一前缀 |
| `@GetMapping` | 只接收 GET 请求 |
| `@PostMapping` | 只接收 POST 请求 |
| `@PutMapping` | 只接收 PUT 请求 |
| `@DeleteMapping` | 只接收 DELETE 请求 |
| `@PathVariable` | 从 URL 路径里取参数，如 `/selectById/1` |
| `@RequestParam` | 从 `?id=1` 查询参数里取值 |
| `@RequestBody` | 把请求体 JSON 转成 Java 对象 |

完整请求链路：

```text
浏览器 / Apifox
   → EmployeeController
   → EmployeeService
   → EmployeeMapper 接口
   → EmployeeMapper.xml
   → MySQL
   → 原路返回 JSON
```

## 14. 增删改操作（任务 4）

对应讲义：`4. MyBatis 增删改操作练习`。

### 14.1 Mapper 接口增加三个方法

```java
int insert(Employee employee);

int update(Employee employee);

int deleteById(Integer id);
```

返回值 `int` 表示**受影响的行数**：

- 新增成功：1；
- 修改成功：1；
- 删除成功：1；
- 没找到记录：0。

### 14.2 XML 增加 `<insert>`、`<update>`、`<delete>`

```xml
<!-- 新增：useGeneratedKeys 把自增主键回填到 employee.id -->
<insert id="insert" useGeneratedKeys="true" keyProperty="id">
    INSERT INTO employee (name, sex, no, age, description)
    VALUES (#{name}, #{sex}, #{no}, #{age}, #{description})
</insert>

<!-- 修改 -->
<update id="update">
    UPDATE employee
    SET name        = #{name},
        sex         = #{sex},
        no          = #{no},
        age         = #{age},
        description = #{description}
    WHERE id = #{id}
</update>

<!-- 删除 -->
<delete id="deleteById">
    DELETE FROM employee WHERE id = #{id}
</delete>
```

`useGeneratedKeys="true" keyProperty="id"` 的作用：

- 数据库里 `id` 是自增的，插入时不需要传 `id`；
- 插入成功后，MyBatis 会把数据库生成的主键值回填到 `employee.id`，方便后续使用。

## 16. 常见报错排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `Table 'xm_pro.employee' doesn't exist` | 数据库名写成了 `xm_pro`，但表在 `xm-pro` | 改 `application.yml` 的 URL 为 `xm-pro`，或执行 `db/init.sql` |
| `Invalid bound statement (not found)` | XML 的 `namespace` 或 `id` 和 Mapper 接口对不上；XML 没被加载 | 检查 `namespace` 是否为接口全限定名，方法名是否和 `id` 一致，`mapper-locations` 是否正确 |
| 浏览器 404 Whitelabel Page | Controller 没扫描到，或改完代码没重启；路径写错 | 确认 `@RestController`、`@RequestMapping`，重启项目 |
| 浏览器 405 Method Not Allowed | 用 GET 访问了 POST/PUT/DELETE 接口 | 换 Apifox/Postman，选择正确请求方式 |
| 400 Bad Request | POST/PUT 没传 JSON 请求体，或 `Content-Type` 不对 | 设置 `Content-Type: application/json`，请求体写合法 JSON |
| 返回 `{"code":"500","msg":"系统错误"}` | 后端抛异常，被全局异常处理捕获 | 看 IDEA 控制台 `ERROR` 堆栈，通常会看到真实 SQL 错误 |
| `Port 8080 was already in use` | 端口被占用 | 关掉旧进程，或改 `server.port` |
| `Access denied for user 'root'` | 数据库密码不对 | 改 `application.yml` 的 `password` |
| 中文乱码 | 数据库/连接字符集不对 | 库、表用 `utf8mb4`，URL 带 `characterEncoding=utf-8` |
| 控制台 `description` 显示 `<<BLOB>>` | `LONGTEXT` 类型在 MyBatis 日志里的正常显示 | 不影响接口返回，忽略即可 |
| 修改/删除返回“修改失败/删除失败” | 传入的 id 不存在 | 先查 `selectAll` 确认 id |

### 16.1 为什么 404 和 405 不会进 GlobalExceptionHandler？

`GlobalExceptionHandler` 处理的是 Controller 内部抛出的异常。URL 根本找不到对应方法时，Spring MVC 直接返回 404；请求方法不对时返回 405，这两种情况通常不会进入你的 `@ExceptionHandler`。

### 16.2 改完代码必须重启

项目没有引入 `spring-boot-devtools`，修改 Java 代码后必须重新运行 `SpringbootApplication`，否则运行的还是旧 class，常见表现就是“代码明明改了，接口还是 404/旧结果”。

## 17. 讲义核心代码解释（复习用）

### 17.1 Controller 逐行

```java
@RestController
@RequestMapping("/employee")
public class EmployeeController {
```

- `@RestController` = `@Controller + @ResponseBody`；
- `@ResponseBody` 让方法返回值直接变成 JSON，而不是跳转页面；
- `@RequestMapping("/employee")` 给类里所有接口加统一前缀。

```java
@Resource
private EmployeeService employeeService;
```

- 从 Spring 容器里找到 `EmployeeService` 对象并注入；
- Controller 不直接操作数据库，只调用 Service。

```java
@GetMapping("/selectAll")
public Result selectAll() {
    List<Employee> list = employeeService.selectAll();
    return Result.success(list);
}
```

执行顺序：

1. 浏览器请求 `/employee/selectAll`；
2. Spring 找到 `selectAll()`；
3. 调用 Service；
4. Service 调用 Mapper；
5. Mapper 找到 XML 里的 `selectAll`；
6. 执行 SQL，返回 `List<Employee>`；
7. `Result.success(list)` 包装成 JSON。

### 17.2 Service 逐行

```java
@Service
public class EmployeeService {
```

- `@Service` 把类注册成 Spring Bean；
- Controller 才能用 `@Resource` 注入它。

```java
@Resource
private EmployeeMapper employeeMapper;
```

- 注入 MyBatis 生成的 Mapper 代理对象；
- Service 是 Controller 和 Mapper 之间的桥梁。

### 17.3 Mapper 和 XML 的对应关系

```java
List<Employee> selectAll();
```

对应：

```xml
<select id="selectAll" resultType="com.example.entity.Employee">
    SELECT id, name, sex, no, age, description FROM employee ORDER BY id
</select>
```

- 接口方法名 `selectAll` = XML 的 `id="selectAll"`；
- `resultType` 告诉 MyBatis 每一行封装成 `Employee`；
- 多条记录自动组装成 `List<Employee>`。

### 17.4 分层职责

| 层 | 职责 | 不该做什么 |
|---|---|---|
| Controller | 接收请求、返回 JSON | 不写 SQL、不直接操作数据库 |
| Service | 业务逻辑、事务、分页 | 不处理 HTTP 请求 |
| Mapper | 定义数据库操作方法 | 不写业务判断 |
| XML | 写 SQL | 不写 Java 逻辑 |
