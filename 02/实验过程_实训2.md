## 1. 数据绑定练习（ref 与 reactive）

操作步骤：

1. 用 `reactive` 定义一组复杂数据（字符串、数字、布尔、数组混在一起），用 `ref` 定义单个基础数据。
2. 在 `<template>` 里用双大括号插值把它们渲染出来。

```vue
<script setup>
import { reactive, ref } from 'vue'

const data = reactive({
  school: '安徽中医药大学',
  no: 168,
  ok: true,
  colleges: ['信工院', '中医学院', '药学院', '针灸学院'],
})
const score = ref(55)
</script>

<template>
  <p>【插值】学校：{{ data.school }}，学号：{{ data.no }}，在校：{{ data.ok }}</p>
  <p>【条件】当前分数 {{ score }}：</p>
</template>
```

观察结果：页面显示"学校：安徽中医药大学，学号：168，在校：true"。布尔值 `true` 被直接渲染成字符串 `true`。

两者的区别与用法：`ref` 用于数字、字符串、布尔这类基础类型，在 JS 里读写要加 `.value`（模板里不用）；`reactive` 用于对象和数组，一次把一组相关数据装在一起，读写直接访问属性、不用 `.value`。

截图：页面第一行插值结果。

## 2. 双向数据绑定 v-model 练习

操作步骤：

1. 在上面那个 `reactive` 对象里已有 `school` 字段。
2. 加一个原生 `<input>`，用 `v-model="data.school"` 绑定它。
3. 在输入框里改文字，看上面那行插值是否同步变化。

```html
<p>【v-model】<input v-model="data.school" style="width: 200px" /> 上面文字会实时跟着变</p>
```

观察结果：在输入框里把"安徽中医药大学"改成别的字，上方那行"学校："立刻跟着变；反过来在代码里改初值，输入框内容也会变。这就是双向：数据到视图、视图到数据都自动同步，不需要手写监听。

截图：输入框改字前后各一张，对比上方文字同步变化。

## 3. Vue3 条件语句练习

操作步骤：

1. 用 `ref` 定义一个分数 `score`，初值 55。
2. 用 `v-if` / `v-else-if` / `v-else` 三条分支渲染三种文字，并给不同颜色。
3. 加两个按钮改分数，观察分支切换。

```html
<p v-if="score >= 90" style="color: green">优秀</p>
<p v-else-if="score >= 60" style="color: orange">及格</p>
<p v-else style="color: red">不及格</p>
<button @click="score += 10">加 10 分</button>
<button @click="score = 55">重置</button>
```

观察结果：初值 55 显示红色"不及格"；点一次"加 10 分"变成 65，显示橙色"及格"；点到 90 以上显示绿色"优秀"。同一时刻页面上只存在一个 `<p>`，不满足条件的分支是**没渲染到 DOM 里**，不是隐藏。

截图：三种分数状态各一张（55 不及格、65 及格、90 以上优秀）。

## 4. Vue3 循环语句练习

操作步骤：

1. 在 `reactive` 数据里放一个学院数组。
2. 先用 `v-for` 遍历成 `<li>` 列表。
3. 再按要求把同一个数组遍历成下拉框 `<select>` 里的 `<option>`，并用 `v-model` 接住选中值。

```html
<ul>
  <li v-for="(item, index) in data.colleges" :key="index">{{ index + 1 }}. {{ item }}</li>
</ul>

<select v-model="data.myCollege">
  <option value="">请选择</option>
  <option v-for="c in data.colleges" :key="c" :value="c">{{ c }}</option>
</select>
<p>下拉框当前选中值：{{ data.myCollege || '（还没选）' }}</p>
```

观察结果：列表渲染出 4 行；下拉框展开后有"请选择"加 4 个学院，选中"药学院"后下方那行同步显示"药学院"。

注意 `:key` 要绑上。`v-for` 不写 `:key` 时编辑器会告警，key 是 Vue 复用节点的凭据。

截图：列表加下拉框展开状态一张，选中某个学院后的结果一张。

## 5. Vue3 事件处理练习

### 5.1 单击事件 v-on / @click

```html
<p>【@click】点赞数：{{ count }} <button @click="count++">点赞 +1</button></p>
```

完整写法是 `v-on:click="count++"`，`@click` 是它的缩写，两者完全等价。点一次数字加一。

截图：点几次之后数字不为 0 的页面。

### 5.2 v-bind 动态属性绑定（样式与图片 src）

完整写法 `v-bind:style`，冒号缩写 `:style`。绑样式：

```js
const box = reactive({ width: '100px', height: '100px', backgroundColor: 'red', marginTop: '10px' })
const toggleColor = () => {
  box.backgroundColor = box.backgroundColor === 'red' ? 'blue' : 'red'
}
```

```html
<div :style="box"></div>
<button @click="toggleColor">切换方块颜色</button>
```

绑图片地址：

```js
const data = reactive({ imgUrl: '/img/shihu.jpg' })
const toggleImg = () => {
  data.imgUrl = data.imgUrl === '/img/shihu.jpg' ? '/img/juhua.jpg' : '/img/shihu.jpg'
}
```

```html
<img :src="data.imgUrl" style="width: 200px; height: 150px; object-fit: cover" />
<p>当前 src 值：{{ data.imgUrl }}</p>
<button @click="toggleImg">换一张图片</button>
```

观察结果：点"切换方块颜色"，红块变蓝块；点"换一张图片"，`<img>` 从石斛换成滁菊，同时下面那行打印出来的 src 字符串也跟着变。这两个例子说明：**属性值只要来自 JS，就必须用冒号绑定**，写成 `src="data.imgUrl"` 的话浏览器会把 `data.imgUrl` 当成一段字面路径去请求，图片必然裂。

图片放在 `public/img/` 下，用 `/img/xxx.jpg` 引用（`public` 里的文件按根路径直接访问，不用 import）。

截图：红色方块一张、蓝色方块一张；石斛图一张、换成滁菊一张。

### 5.3 onMounted 生命周期

```js
import { onMounted } from 'vue'

onMounted(() => {
  console.log('Home.vue 加载完成！')
  mountedAt.value = new Date().toLocaleTimeString()
  alert('页面加载完成，onMounted 钩子已触发')
})
```

观察结果：每次刷新页面都会先弹一个提示框，点掉之后才能操作页面；控制台里同时有那行 log。页面正文里我额外打印了钩子的实际触发时刻，方便从截图上直接看到它跑过。

## 6. 遇到的问题与解决方法（本讲汇总）

1. **`v-for` 不写 `:key` 编辑器一直告警。** 加上 `:key="index"` 或 `:key="item"` 解决。
2. **图片写 `src="data.imgUrl"` 显示不出来。** 因为没加冒号，被当字面路径。改成 `:src="data.imgUrl"` 正常。
3. **`ref` 的值在 JS 里改不动。** `ref` 包的是个带 `.value` 的对象，JS 里必须写 `score.value = 65`，只有模板里可以省掉 `.value`。
4. **`alert` 弹窗挡住了自动化截图。** 原生弹框会阻塞页面渲染，脚本截图时页面会卡在那里等人工点掉。解决办法是截图时用 `?noalert=1` 这个参数跳过弹框，同时在页面上留一行可见的触发时刻作为证据；平时不带参数访问，弹框照常弹。
5. **`onMounted` 的时机。** 它是"组件挂载完成"，也就是虚拟 DOM 已经渲染成真实 DOM、可以访问元素了，但不等于页面里所有图片和外链资源都下载完了。要等资源全加载完得用别的手段。

## 7. 本讲小结

| 语法 | 作用 | 一句话记法 |
|---|---|---|
| `{{ }}` | 文本插值 | 把 JS 的值变成页面上的字 |
| `ref` | 基础类型响应式 | JS 里读写要 `.value` |
| `reactive` | 对象/数组响应式 | 一组数据打包管 |
| `v-model` | 双向绑定 | 表单和变量互相同步 |
| `v-if` / `v-else-if` / `v-else` | 条件渲染 | 不满足的分支不进 DOM |
| `v-for` | 列表渲染 | 必须配 `:key` |
| `@click` | 事件绑定 | `v-on:click` 的缩写 |
| `:src` / `:style` | 属性绑定 | 值来自 JS 就要加冒号 |
| `onMounted` | 生命周期 | 组件挂到页面上之后跑一次 |
